Lintas Studio website
A single-file company website. No build step and no dependencies.
Run it
Open `index.html` in a browser.
Edit it
Colors and fonts: the `:root` blocks at the top of `<style>`.
Text: search `index.html` for the section you want (hero, about, process, services, portfolio, reviews, contact).
Replace all placeholder names, figures, quotes, the email address and the studio address.
Publish it
Push this folder to GitHub, then enable Settings > Pages and serve from the main branch.
Fonts load from Google Fonts, so the page needs an internet connection to show them as designed.
